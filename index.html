📻 1. Ställ in stereon

Börja med stereon så neutral som möjligt.

  • EQ: Flat / 0 dB
  • Loudness: Av
  • Bass boost: Av
  • Extra sound effects: Av
  • Fader: 0
  • Balance: 0
  • Sub level: 0 dB som startpunkt
💡 Börja neutralt. Det är mycket lättare att höra vad DSP:n faktiskt gör när stereons egna ljudförbättringar inte påverkar signalen.

⚡ 2. Gain – ställ nivåerna rätt

Gain är inte en volymkontroll. Den används för att matcha signalnivån från stereon/DSP mot slutstegets ingång.

Grundprincip

Börja med stereon på en bestämd hög men ren volymnivå. Använd sedan gain för att få önskad uteffekt utan clipping.

Målspänning = √(RMS-effekt × impedans)

Exempel: 300 W RMS @ 4 Ω ≈ 34,6 V AC.

⚠️ Ange alltid faktisk RMS-effekt och den impedans som slutsteget verkligen belastas med.

🎚️ 3. HPF, LPF och filterlutning

Filtren bestämmer vilka frekvenser som får passera. Lutningen anger hur snabbt signalen dämpas efter delningsfrekvensen.

Vanliga lutningar

6 dB/okt 1:a ordningen – mycket mjuk
12 dB/okt 2:a ordningen – vanlig
18 dB/okt 3:e ordningen
24 dB/okt 4:e ordningen – brant
36–48 dB/okt Mycket brant – används när det finns anledning

Vad betyder det?

Om ett HPF ligger på 80 Hz och har 12 dB/oktav kommer signalen under delningen att dämpas med ungefär 12 dB för varje oktav nedåt.

  • 80 Hz = delningsområdet
  • 40 Hz = ungefär −12 dB
  • 20 Hz = ungefär −24 dB
💡 Exakta nivåer beror även på filtertypen och hur DSP:n implementerar filtret.

🔊 4. Subwoofer

Startpunkt

  • LPF: ca 70–90 Hz
  • Lutning: 18–24 dB/okt
  • EQ: 0 dB till att börja med
  • Fas: börja på 0°

Justera sedan LPF så att subwoofern smälter ihop med middbasen istället för att låta som en separat högtalare.

Subsonic

På en portad låda bör subsonic väljas med hänsyn till lådans avstämningsfrekvens och elementets tålighet.

🔈 5. Middbas i dörr

  • HPF: ca 60–100 Hz
  • LPF: ca 2–4 kHz
  • Lutning: 12–24 dB/okt
⚠️ Om middbasen slår hårt eller bottnar, höj HPF istället för att bara sänka gain.

🎤 6. Mellanregister

  • HPF: ofta ca 150–300 Hz
  • LPF: ofta ca 2–4 kHz
  • Lutning: 12–24 dB/okt

Om röster blir hårda eller skrikiga kan området kring ungefär 1–4 kHz vara värt att undersöka.

📣 7. Diskant

  • HPF: följ diskantens rekommenderade delning
  • Lutning: ofta 12–24 dB/okt eller brantare
  • EQ: börja på 0 dB
⚠️ Överskrid inte tillverkarens rekommenderade lägsta delningsfrekvens.

🎵 8. EQ – gör detta sist

Börja alltid med EQ på 0 dB.

Försök i första hand att skära bort problem istället för att höja alla områden som saknas.

20–60 Hz Djupbas / subbas
60–120 Hz Bas / tryck
120–250 Hz Värme / kropp
250–800 Hz Värme / risk för grötighet
800 Hz–2,5 kHz Röst / attack
2,5–6 kHz Närvaro / skrikighet
6–12 kHz Diskant / detalj
12–20 kHz Luft

🔄 9. Fas och polaritet

Kontrollera att högtalarna är kopplade med rätt polaritet. Testa därefter 0° och 180° mellan exempelvis sub och frontsystem om DSP:n har den funktionen.

⏱️ 10. Tidskompensation

Högtalarna sitter olika långt från förarens öron. DSP:n kan fördröja de närmare högtalarna.

Ljudets hastighet ≈ 343 m/s

Det motsvarar ungefär 2,9 ms per meter.

Gain-kalkylator

Så fungerar det
